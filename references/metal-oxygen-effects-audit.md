# Systematic metal–oxygen effect audit

The user identified repeated missing combustion visuals, first for Li/O2 and then Fe/O2. Reviewed all 77 existing neutral two-element oxygen records and compared the relevant element-specific air/oxygen sections in the checksum-verified private source archive. Existing condition/product review decisions are preserved. Thirty-three effect records are corrected through the explicit allowlist in [metal-oxygen-effects-review.json](../data/reactions/metal-oxygen-effects-review.json). This is not an automatic fire rule for every metal.

Corrections cover Ba (two oxide/peroxide endpoints), Be, Bi, Cs, Ca, Mn, K, Rb, Na, Sr, Ti, Zn, Cd, Ce, Dy, Er, Eu, Gd, Hf, Ho, La, Lu, Nd, Pr, Sm, Tb, Tm, Yb, Y, Zr, the existing Mg combustion example and the existing pure-oxygen sodium-peroxide example. Air-combustion observations are not relabeled as independently measured pure-oxygen behavior or quantitative intensity predictions. The source archive is inspected without restoring or republishing publisher originals.

The common failure was effect metadata: sources explicitly describe burning, but records only requested solid deposition. Each selected record now includes heat and the combustion effect. Where no actual flame is described, a glowing-solid visual avoids inventing a tall gas flame. Ti's explicitly reported white flame and Bi's bluish-white flame use those colors. Powder/fine-form restrictions for Be/Mn and oxide-film qualifications for Hf/Zr remain visible in observations. Existing principal/coproduct, source-phase and approximate-oxide caveats remain. No explosions, gas production or toxic effects are inferred from a metal name or oxygen alone.

The cited WebElements pages supply the species-specific combustion evidence. Representative live rechecks: [titanium](https://www.webelements.com/titanium/chemistry.html), [bismuth](https://www.webelements.com/bismuth/chemistry.html), [manganese](https://www.webelements.com/manganese/chemistry.html), [zirconium](https://www.webelements.com/zirconium/chemistry.html), [cerium](https://www.webelements.com/cerium/chemistry.html), [zinc](https://www.webelements.com/zinc/chemistry.html), and [hafnium](https://www.webelements.com/hafnium/chemistry.html). Each correction records source URL and reason; archived evidence paths/checksums accompany the bulk review entries. Na peroxide gains the already-catalogued WebElements sodium reference alongside its original OpenStax conditions.

Generic heated copper/cobalt/palladium oxidation, Al surface passivation, controlled-oxygen peroxide endpoints without an explicit burning observation, and incomplete reference-only equations are not indiscriminately turned into fire. Existing pure-oxygen Fe/Mg/Na constraints remain enforced. Thirty-three effects change; all 435 reaction equations, activations, required atmospheres, product phases, and execution states are compared to snapshot .7 and verified unchanged. No equation-only records are promoted to playable.

Snapshot .8 retains 435 entries, 242 modeled and 193 equation-only, 532 substances and 131 source URLs. All 509 tests pass, including positive combustion display, actual oxygen-condition execution, explicit flame colors, glow/flame distinction and negative non-combustion cases. Production TypeScript/Vite build passes. Teacher review and browser visual inspection remain pending. The local app version is 1.5.4; this change is included in the 1.5.4 release.
